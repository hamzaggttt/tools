# MediaTools v2

A modern, professional suite of media tools built with privacy and speed in mind.

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open in browser**:
   Navigate to `http://localhost:5173`.

## 🛠 Features

- **Background Remover**: Pro AI-powered removal.
- **Caption AI**: Advanced timeline-style editor with AI transcription.
- **Video Converter**: Local browser-side conversion (FFmpeg.js).
- **Image Converter**: Instant PNG/JPG/WEBP conversion.
- **Auphonic Enhancer**: Pro audio mastering.
- **Thumbnail Generator**: AI image generation and face tracking.

## 🏗 Backend

The tools rely on the `video-backend` for server-side tasks (AI transcription, Auphonic proxy, etc.). Ensure the backend is running on `localhost:3000`.
